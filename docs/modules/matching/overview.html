L4 Code · component overview — matching

Index › L2 Container › tgscout › matching

matching is the one component of tgscout. It owns the messages it has seen, the cursor of each chat and the decisions. Two primary adapters drive it: the collector reads Telegram, the matcher workers take messages from the queue. It calls five ports: the settings, the repository, the queue, the LLM and the notifier.
