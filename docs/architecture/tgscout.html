L3 Component — tgscout

The parts inside the tgscout app. The picture comes once the parts are agreed.

Agreed so far

  • At peak, messages wait in an in-memory queue (a Go channel) before the LLM judge.
  • The cursor is the last processed message ID of each chat, kept in SQLite.
  • After a restart, catch-up rereads from Telegram from the cursor and skips IDs already in SQLite: nothing is lost.
