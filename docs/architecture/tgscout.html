Folders and layers

Proposal: the repository layout by the kit rules for Go. The repository is the service namespace (one service), so the workspace folder tgscout/ and e2e/ sit at its root. Each adapter folder is <what>/<technology>: llm/openai is the LLM over the OpenAI-compatible API, requests/yaml is the search requests read from a YAML file. Hexagon of matching

Proposal: the collector and the matcher workers call the core; the queue, llm, notifier and repositories implement its ports

Agreed so far

  • At peak, messages wait in an in-memory queue (a Go channel) before the matcher.
  • The cursor is the last processed message ID of each chat, kept in SQLite.
  • After a restart, catch-up rereads from Telegram from the cursor and skips IDs already in SQLite: nothing is lost.
