Version 1 — slice order

The walking skeleton unblocks the rest; each slice runs after the one before it and adds one use case end to end

  1. walking-skeleton — workspace, CLI start and stop, SQLite schema, checks · 0.1.0
  2. hierarchical-settings — tgscout.yaml, chat → request → root overrides · 0.2.0
  3. telegram-sign-in — tgscout's own account, private session, chat lookup · 0.3.0
  4. live-matching — new message → queue → matcher → llm → decision, on the console · 0.4.0
  5. owner-notification — private message to the owner, send then mark · 0.5.0
  6. catch-up — missed history from the cursor at start, summary · 0.6.0
  7. delivery-resilience — retries, reconnect, graceful stop, crash tests · 0.7.0
  8. quality-targets — latency, status line, load, catch-up and size tests · 0.8.0
